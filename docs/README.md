# Screenshots

Drop the images referenced by the READMEs here:

| File | What to capture |
| --- | --- |
| `screenshot-sphere.png` | Sphere mode (◎) — circular window with a beatmap background |
| `screenshot-library.png` | Library view — track list, search bar, BPM filter |

PNG, cropped to the window itself (no desktop around it). Keep the filenames as-is;
`README.md` and `README-fr.md` link to these exact paths.

The current ones show a demo library: invented titles and artists, abstract backgrounds
generated for the occasion, so no beatmap art is redistributed. The library is captured
in a 400×760 window (resized from the default 380×580 to show more tracks) with the
osu! Dark theme, the sphere with the Sakura theme, both at 2× for high-DPI screens.
Replace them with captures of your own library whenever you like.
